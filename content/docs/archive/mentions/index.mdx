## Placeholder structure

When ingesting from Notion, each row should include:

1. **Source URL** (required before publishing here)
2. **Date observed**
3. **Claim** (one line — e.g. job title used)
4. **Normalized to** (link to canonical doc section)
5. **Status** — match, conflict, or ignore

Do not invent URLs in git; import only verified public links.
